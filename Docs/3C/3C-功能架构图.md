# Event_Stream 3C 功能架构图

> 基于 `D:\unity\Event_Stream` 当前 `main` 工作区源码静态分析。3C 按 Character、Camera、Control 划分。

```mermaid
flowchart LR
    subgraph Control[Control · 输入与决策]
        Device[键鼠 / 手柄]
        InputAsset[PlayerInput\nInput System 生成类]
        InputManager[PlayerInputManager\n统一读取移动、视角、攻击、跳跃、冲刺]
        FSM[PlayerFSM\n状态注册、当前状态、SetState、OnTink]
        States[PlayerStateBase 状态族\nIdle / Walk / Run / Sprint / Dash\nJump 系列 / Attack / Landing]
    end

    subgraph Character[Character · 角色行为]
        Movement[PlayerMovementController\n移动意图、地面检测、跳跃、朝向]
        Base[PlayerControllerBase\nAnimator / CharacterController / 重力 / Root Motion]
        Combo[PlayerComboController\n轻重攻击入口]
        ComboBase[PlayerComboControllerBase\n索敌、面向、位移匹配、伤害触发]
        ComboData[CharacterComboSO\nCharacterComboDataSO]
        Animator[Animator\n动画层、Tag、参数、动画事件]
        Motor[CharacterController\n水平 Root Motion + 垂直重力位移]
        EventBus[GameEventManager\n伤害事件]
        Health[CharacterHealthControllerBase\n玩家 / 敌人生命与受击反馈]
        Pool[GamePoolManager / GameTimerManager\n脚步与攻击音效]
    end

    subgraph Camera[Camera · 视角]
        CameraController[TP_CameraController\n旋转、俯仰限制、目标距离]
        CameraCollider[CameraCollider\n射线避障、距离平滑]
        CameraTarget[CameraTarget\n第三人称跟随枢轴]
        MainCamera[Main Camera Transform]
        FreeLook[FreeLookZoom\nCinemachineFreeLook 可选缩放分支]
    end

    Device --> InputAsset --> InputManager
    InputManager -->|移动 / 跳跃 / 冲刺 / 攻击| Movement
    Movement -->|Awake 注册 12 个状态| FSM
    FSM -->|每帧 OnTink| States
    States -->|EnterState / ExitState| Movement
    States -->|CrossFade / Play| Animator
    Movement --> Base
    Base -->|OnAnimatorMove| Motor
    Movement -->|相机朝向参与移动旋转| MainCamera

    InputManager -->|Look / Scroll| CameraController
    CameraTarget --> CameraController
    CameraController -->|LateUpdate 设置旋转和位置| MainCamera
    CameraCollider -->|Raycast 修正 currentDistance| CameraController
    FreeLook -.独立可选实现.-> MainCamera

    Movement --> Combo
    Combo --> ComboBase
    ComboBase --> ComboData
    ComboBase -->|动画事件 ATK| EventBus
    EventBus --> Health
    Animator -->|命中帧 / 声音事件| ComboBase
    Movement -->|脚步声| Pool
    ComboBase -->|攻击声| Pool
```

## 一帧内的主流程

```mermaid
sequenceDiagram
    participant I as PlayerInputManager
    participant M as PlayerMovementController
    participant F as PlayerFSM
    participant S as 当前 PlayerState
    participant A as Animator
    participant C as CharacterController
    participant Cam as TP_CameraController

    I-->>M: 提供移动、攻击、跳跃、冲刺输入
    M->>M: 高度 / 地面 / 重力 / 移动标志计算
    M->>A: 更新 HasInput、IsRun、Speed 等参数
    M->>F: OnTink()
    F->>S: OnUpdate()
    S->>F: 满足条件时 SetState(next)
    F->>S: OnExit → 替换状态 → OnEnter
    S->>M: EnterState(next)
    S->>A: CrossFade / Play
    A->>M: OnAnimatorMove()
    M->>C: Root Motion 水平位移 + 垂直速度
    I-->>Cam: Look / Scroll
    Cam->>Cam: Update 读输入，LateUpdate 跟随
```
